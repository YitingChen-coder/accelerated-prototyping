# Accelerated Prototyping — Assignment 1

## Project Direction
- Idea: An AI-powered mock interview coach for software engineering (SWE) candidates.
- Audience: CS students and early-career software engineers preparing for technical interviews.
- Visitors should immediately understand that the product simulates realistic SWE interviews, provides personalized feedback, and helps them improve.
- Primary action: Start a mock interview.
- Do not invent design decisions on the user's behalf.

## Assignment Goals
- Create 25 landing pages (v01–v25) for the same idea, plus a gallery that tells the iteration story.
- Explore different layouts, audiences, moods, eras, and tones early on; changing only colors or fonts does not count as a new direction.
- At least 20 designs should have clearly distinct concepts and aim to stand apart from classmates' work.
- Use user feedback to select, combine, and refine directions; v20–v25 should converge toward the final choice.
- Work iteratively, one design direction at a time. Do not generate all 25 versions in one shot.

## Technical and Page Requirements
- Use only plain HTML, CSS, and optional JavaScript.
- No React, Next.js, Vue, or other frameworks.
- No build systems, external APIs, databases, or data storage.
- Root index.html is the gallery: show every version's thumbnail, link, short change note, and the final choice.
- Each version must be independently accessible and include a link back to the gallery.
- Preserve earlier versions; explain any changes to them to avoid overwriting the iteration record.

## Process and Delivery
- Use real Git commits to document iteration; do not fabricate history.
- Deliver a personal GitHub repository and a working gallery on Vercel's free Hobby plan; check all pages and links before submission.
- Help the user explain the design process, convergence rationale, and how they used and corrected the coding agent.
